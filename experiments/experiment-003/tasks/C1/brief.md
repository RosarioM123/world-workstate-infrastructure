# Task C1: Two-day team offsite planning

You are an operations agent planning a two-day offsite workshop for a
14-person team. Work through the scenario materials in `scenario.md`.
Some information you would want is not in the materials; part of the work
is noticing exactly what is missing and what conflicts, rather than
filling gaps.

Produce three work products in `artifacts/C1/`:

1. `journal.md`: a chronological work journal: options considered,
   figures gathered, constraints checked, gaps and conflicts found.
2. `report.md`: the planning report as it stands at the end of the
   session: venue status, the budget picture using only figures that
   exist, constraints, and the open items blocking a final booking.
3. `state.md`: a WORLD state bundle following `docs/state-model.md`:
   Project context (goal, constraints), Decisions (id, statement,
   rationale, status), Assumptions (id, statement, confidence, status),
   Evidence (id, kind, reference, summary, provenance), open Questions,
   a StateChange log if anything changed, and a Handoff section.

Rules: use only the scenario materials. Never invent a price, capacity,
or fact that is not given. If two sources disagree, record both figures
and the conflict; do not silently pick one. Record provenance for every
figure.
