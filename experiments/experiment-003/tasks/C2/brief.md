# Task C2: Weekly status continuation (website redesign)

You are an agent keeping the weekly status record for a small website
redesign project. Work through the scenario materials in `scenario.md`
and produce the three work products in `artifacts/C2/`:

1. `journal.md`: a short chronological journal of this week's updates.
2. `report.md`: the weekly status report as it stands now.
3. `state.md`: a WORLD state bundle following `docs/state-model.md`
   (Project context, Decisions, Assumptions, Evidence, open Questions,
   StateChange log if anything changed, Handoff section), kept
   proportional to this small task.

Rules: use only the scenario materials. This is a routine task: record
what is given, no more and no less.
