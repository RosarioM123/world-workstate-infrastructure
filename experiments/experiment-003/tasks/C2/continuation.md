# Continuation assignment (C2)

You are picking up the weekly status record for a website redesign
project from a previous agent. Using only the handoff material provided,
produce a Continuation Document with exactly these sections:

1. **Where things stand:** the project's current status.
2. **Decisions in force:** any decisions in effect, with reasons; if there
   are none of consequence, say so.
3. **Assumptions and facts:** any assumptions, labeled as such with
   confidence, distinct from the given facts.
4. **Constraints:** any standing constraints; if there are none beyond the
   recorded schedule, say so.
5. **What changed and why:** anything that changed; if nothing of
   substance changed, say so.
6. **Open questions and missing information:** what is still unknown.
   Flag it; do not invent a confirmation.
7. **Next actions:** the concrete next steps.
8. **Status update draft:** a short status update (at most about 150
   words) for the team, covering this week's progress and next steps.
