# Task R1: Product specification for Team Notes v2

You are a product agent drafting the specification for "Team Notes", a
note-taking app, version 2. Work through the scenario materials in
`scenario.md` in order: Part 1 is the original spec draft; Part 2 contains
two official updates that change requirements. Track every version: a
successor reading your work must be able to tell what the requirement
used to be, what it is now, and why it changed.

Produce three work products in `artifacts/R1/`:

1. `journal.md`: a chronological work journal: what you drafted, what the
   updates changed, and your reasoning.
2. `report.md`: the specification summary as it stands at the end of the
   session (current requirements only, with a change history section).
3. `state.md`: a WORLD state bundle following `docs/state-model.md`:
   Project context (goal, constraints), Decisions (id, statement,
   rationale, status, supersedes links), Assumptions (id, statement,
   confidence, status), Evidence (id, kind, reference, summary,
   provenance), open Questions, a StateChange log recording each revision
   in order with its reason, and a Handoff section.

Rules: use only the scenario materials. Only the latest version of each
requirement is authoritative, but earlier versions must remain visible as
superseded, with the reason for each change and where the change came
from.
