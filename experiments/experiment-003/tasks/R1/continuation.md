# Continuation assignment (R1)

You are resuming specification work on Team Notes v2 that a previous
product agent started. Using only the handoff material provided, produce
a Continuation Document with exactly these sections:

1. **Where things stand:** the current, authoritative requirements for the
   v2 launch.
2. **Decisions in force:** every decision that currently governs the spec,
   with the reason it was made. Separately list any decisions or
   requirements that are no longer in force.
3. **Assumptions and facts:** the assumptions the spec rests on, labeled
   as assumptions, with confidence, including any assumption that turned
   out not to hold. Keep facts distinct from assumptions.
4. **Constraints:** every standing constraint on the v2 scope.
5. **What changed and why:** every requirement that changed during the
   prior session, what it changed from and to, why it changed, which
   version is authoritative now, and where each change came from.
6. **Open questions and missing information:** what is still undecided or
   unknown. Flag it; do not invent answers.
7. **Next actions:** the concrete next steps for the spec and build, in
   order. Do not propose building anything the current scope excludes.
8. **Authoritative spec summary:** a short summary (at most about 300
   words) of the v2 launch spec as it currently stands, suitable to send
   to the build team, with a brief change history.
